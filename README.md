### About me

I'm a DevOps engineer from Kerala. Most of my work happens in the space between "the code is ready" and "it's running reliably for real users". That means cloud infrastructure, Linux servers, pipelines, and the monitoring that catches problems before anyone files a ticket.

These days I'm a Senior DevOps Engineer at **Psypher AI**, where I run the AWS setup and the release process for our AI products. Before that I spent close to four years at **IIT Delhi**, keeping a research project's infrastructure running while it rolled out to all **28 Indian states**. Procuring servers, setting them up, deploying, and handing each state a working system taught me what operations actually looks like away from a tutorial.

How I like to work:

- **Write it down as code.** If a server was set up by hand, nobody can rebuild it at 2 a.m. Terraform and Ansible fix that.
- **Measure before guessing.** A good dashboard settles an argument faster than any meeting.
- **Keep releases boring.** The best deployment is one nobody remembers happening.
